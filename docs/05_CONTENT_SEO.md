# 05 — Content & SEO Specification

## 1. Core keyword themes

Use naturally, not through keyword stuffing:
- Dubai real estate
- UAE mortgage
- Dubai property finance
- UAE corporate tax
- UAE tax services
- UAE AML compliance
- KYC / CDD
- Dubai property investment
- UAE property finance

Exact SEO strategy should be validated with keyword research before production.

## 3. Content hierarchy

Every page should have:
- One clear H1
- Supporting H2 sections
- Short paragraphs
- Lists where useful
- Clear CTAs

## 4. CTA library

**Primary:**
- Check My Eligibility
- Start Assessment
- Request a Consultation
- Speak to an Expert

**Secondary:**
- Explore Mortgage
- Explore Tax
- Explore AML
- View Resources

## 5. Legal content

All tax, mortgage and AML educational content must be reviewed by appropriate professionals before production publication.

Use disclaimers where necessary.

The demo should distinguish:
- Educational information
- Indicative assessment
- Professional advice
- Actual regulated/official processes

## 6. Resource content model

Each resource should have:
- title
- slug
- category
- excerpt
- publication date
- reading time
- content
- related service
- SEO title
- SEO description
