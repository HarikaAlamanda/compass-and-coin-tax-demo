# 00 — Project Overview

## Compass & Coin — Property, Finance & Compliance Website

**Project type:** Learning project + fully functional demo
**Market:** Dubai / UAE
**Primary services:** Real Estate, Mortgage, Tax, AML
**Primary learning objective:** Learn a repeatable end-to-end website development process that can be reused for future projects.

> Brand reference: supplied Compass & Coin logo. Initial palette and logo-placement guidance are based on visual inspection of that asset.

## 1. Vision

Build a professional website that presents Compass & Coin as a connected Property + Finance + Compliance ecosystem.

The website must be useful enough to function as a realistic demo, while its documentation and code structure must teach the user how to take a future website idea from requirements through deployment.

## 2. Core positioning

**Property. Finance. Compliance.**

Suggested supporting message:

> Your complete UAE property, finance and compliance ecosystem.

The website should connect:
- Real Estate: property buying, selling, leasing and investment
- Mortgage: financing and eligibility guidance
- Tax: UAE tax support and education
- AML: KYC, CDD, risk and compliance support

## 3. Primary audiences

1. Dubai/UAE property buyers
2. Property investors
3. Individuals exploring mortgage financing
4. UAE business owners seeking tax support
5. Businesses requiring AML/compliance support
6. Existing real-estate clients who may need finance or compliance services

## 4. Primary business objective

Generate qualified enquiries.

## 5. Secondary objectives

- Explain the four business areas clearly
- Build trust
- Educate visitors
- Provide useful self-service tools
- Create SEO-ready content architecture
- Demonstrate a scalable modern web architecture

## 7. Key interactive features

### Mortgage Eligibility Calculator

**Inputs:**
- Monthly income
- Existing monthly commitments
- Age
- Property price
- Down payment

**Outputs:**
- Indicative financing amount
- Indicative monthly payment
- Indicative cash requirement
- Indicative term

The calculation is a demo/education tool and must never be presented as bank approval.

### Tax Assessment

A short questionnaire that provides an indicative result and directs users to professional review.

### AML Health Check

A questionnaire that evaluates whether a business appears to have basic AML controls in place. It must be explicitly labelled as a self-assessment, not legal certification.

### Lead Form

Collect:
- Name
- Email
- Phone
- Service of interest
- Optional message
- Consent checkbox

## 8. Design direction

The supplied Compass & Coin logo is the visual source of truth.

**Observed logo characteristics:**
- White background
- Orange-to-red visual gradient
- Compass + property/home symbol
- Bold uppercase wordmark

**Initial brand palette for the demo:**
- Primary orange: approximately #F15A24
- Secondary orange: approximately #F36B3D
- Accent red: approximately #F2292E
- Dark text: #171717
- White: #FFFFFF
- Light neutral: #F7F7F5

Exact brand hex values should be confirmed against the original brand assets before production.

## 9. Logo placement

- Desktop: top-left in the main navigation
- Mobile: top-left
- Preserve aspect ratio
- Do not stretch, recolour or redraw the supplied logo
- Use a transparent-background version in production if available
- Keep adequate clear space around the logo

## 10. Non-goals for the first build

Do not build:
- Real bank application submission
- Real financial approval
- Legal/tax filing
- Government integrations
- Production KYC verification
- Real transaction monitoring
- User accounts
- Payments
- CRM integration
- Complex admin dashboard

These may be future projects.

- Requirements gathering
- User stories
- Acceptance criteria
- Sitemap and user journeys
- Wireframing
- Design systems
- React/Next.js component architecture
- TypeScript
- Forms and validation
- Client-side calculations
- SEO fundamentals
- Accessibility
- Testing
- Git/GitHub
- Deployment
- Environment variables
- AI-assisted development with Claude Code

## 12. Definition of done

The demo is complete when:
- All MVP routes work
- Navigation works
- Responsive layout works
- Logo and brand system are consistently applied
- Mortgage calculator works and validates inputs
- Tax and AML assessments work
- Lead form validates and shows a safe success state
- No major console errors exist
- Basic accessibility checks pass
- SEO metadata exists
- README explains how to run the project
- Project is committed to Git
- Project is deployed
