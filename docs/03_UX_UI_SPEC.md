# 03 — UX / UI Specification

## 1. Brand direction

The supplied Compass & Coin logo is the primary brand reference.

**Visual personality:**
- Premium
- Professional
- Modern
- Dubai-oriented
- Financially credible
- Clear rather than flashy

## 2. Brand palette

Initial palette derived visually from the supplied logo:

| Token | Initial value | Use |
|---|---|---|
| brand-orange | #F15A24 | Primary actions |
| brand-orange-light | #F36B3D | Highlights |
| brand-red | #F2292E | Accent/gradient |
| text | #171717 | Main text |
| muted-text | #666666 | Secondary text |
| background | #FFFFFF | Main background |
| surface | #F7F7F5 | Cards/sections |
| border | #E7E7E7 | Borders |

These are demo values. Confirm official brand specifications before production.

## 3. Logo rules

- Header: top-left
- Desktop height: approximately 36–48px depending on actual asset ratio
- Mobile height: approximately 32–40px
- Preserve original proportions
- Never distort
- Maintain clear space
- Logo click returns Home

## 4. Typography

Use a modern sans-serif family with strong readability.

**Suggested:**
- Headings: Inter or a similar modern sans-serif
- Body: Inter or system sans-serif

Use a limited type scale:
- Display
- H1
- H2
- H3
- Body
- Small/label

## 5. Layout

Use a consistent maximum content width.

**Suggested:**
- max-width: 1200–1280px
- generous section spacing
- 12-column desktop grid concept
- stacked layout on mobile

## 6. Components

Create reusable components:
- Header
- Footer
- Button
- Container
- SectionHeading
- ServiceCard
- FeatureCard
- CTASection
- FAQ
- FormField
- SelectField
- ResultCard
- CalculatorCard
- ArticleCard
- Badge
- Disclaimer

## 7. Interaction principles

- Primary buttons use the brand accent.
- Buttons have hover/focus states.
- Forms show errors close to the field.
- Results appear in a visually distinct card.
- Animations should be subtle and optional.
- Avoid animation that interferes with reading.

## 8. Mobile requirements

- Navigation becomes a menu.
- Cards stack vertically.
- Calculator becomes single-column.
- Buttons should be comfortable to tap.
- No horizontal overflow.
- Text remains readable without zooming.

## 9. Accessibility

- Semantic HTML
- Visible keyboard focus
- Proper form labels
- Alt text for meaningful images
- Decorative images marked appropriately
- Good heading hierarchy
- Do not rely on colour alone to communicate status
- Respect reduced-motion preferences where animations are used

## 10. Imagery

Use Dubai architecture/property imagery selectively.

Avoid making every section a photo banner. Use a combination of:
- Clean gradients
- Architecture
- Simple icons
- Data/assessment cards
- Abstract financial/compliance visuals

## 11. Tone

Clear, professional and approachable.

**Avoid:**
- Guaranteed approval
- Guaranteed returns
- Guaranteed tax savings
- Claims of regulatory certification without evidence
- Fear-based AML messaging
